# Brayman — сайт магазина одежды

Статичный сайт без сборки и зависимостей.

## Структура

```
site/
├── index.html    разметка и тексты
├── style.css     оформление и анимации
├── script.js     свечение курсора, кнопки, появление блоков, игра
├── images/       фото товаров (hat.jpg, polo.jpg)
└── README.md
```

## Запуск

Откройте `index.html` в браузере. Для публикации загрузите папку на любой статический хостинг (Vercel, Netlify, GitHub Pages).

## Что менять

- **Telegram для заказов:** в `index.html` замените `danlekzzz` (все ссылки `https://t.me/danlekzzz`) и в `script.js` в строке `go.href`.
- **Новый товар:** скопируйте блок `<article class="card">` в разделе «Каталог», поменяйте фото, название и `data-c` (категория для фильтра). Для фильтра добавьте кнопку `.pill`.
- **Цены:** добавьте их в тексты карточек и в блок «Соберите свой заказ».
- **Цвета:** переменные в начале `style.css` (`--r1`, `--r2`, `--grad`, `--bg`).
- **Игра:** предметы и очки заданы в `script.js` (`T` и `V`).

Шрифты (Unbounded, Manrope) подключаются из Google Fonts.
